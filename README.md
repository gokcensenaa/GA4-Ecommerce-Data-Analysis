# GA4-Ecommerce-Data-Analysis

## Project Overview

This project analyzes e-commerce user behavior and conversion performance using SQL and Google BigQuery.

The analysis is based on the Google Analytics 4 (GA4) public sample dataset.

## Tools & Technologies

- Google BigQuery
- SQL
- Google Analytics 4 (GA4) Sample Dataset

## Project Objectives

- Analyze user interactions and event data.
- Understand the e-commerce conversion funnel.
- Prepare GA4 event data for further analysis.
- Explore user behavior throughout the shopping journey.

## SQL Queries

1. 01_landing_page_conversion.sql – GA4 event data analysis.
2. `02_ecommerce_conversion_funnel.sql` – E-commerce conversion funnel analysis.
3. `03_ga4_event_data_preparation.sql` – GA4 event data preparation.
4. 04_user_engagement_purchase_correlation.sql – Analysis of the relationship between user engagement and purchases.

## Dataset

Google Analytics 4 public sample dataset:

`bigquery-public-data.ga4_obfuscated_sample_ecommerce`
